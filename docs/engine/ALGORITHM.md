# Trip engine algorithm

1. **Network**: the snapshot is indexed once per version (departures by place, arrivals by place, links). Parent/child places get an assumed 5 min walk (flagged `ASSUMED_LINK`).
2. **Search**: multi-criteria label-setting over (time, price, miss survival, legs). Scheduled legs board the first 3 feasible departures per service. Flexible legs (taxi, walk) are placed as soon as the previous leg allows; taxis wait for their service window (05:00-23:30). Arrive-by is the same search on mirrored time; rules are always asked in real order.
3. **Hard floor**: `ConnectionRules.Required` = alight time of the previous leg + boarding rule of the next (check-in cutoff, boat closure 15, taxi lead 8) + 2 min per passenger beyond two. The assembler re-checks every connection independently; nothing below the floor is returned.
4. **Risk**: each leg's delay is "late with probability q, then exponential with mean m" (priors per mode, blended with `IReliabilityStats` by sample count). Connection miss = P(inbound delay + taxi noise > slack); trip miss = 1 - product of survivals. Unknown history means the prior, never perfect.
5. **Ranking**: tolerance filter (cautious 3 %, balanced 8 %, relaxed 15 % and minimum slack) -> Pareto on (time, price, transfers, risk) -> score = 100 x (1 - weighted penalties), weights time/price/risk/transfers: cautious .25/.15/.50/.10, balanced .35/.25/.30/.10, relaxed .40/.30/.20/.10. Labels: fastest, cheapest, safest, best overall. Backups: ban each run of the best options and re-search; near-duplicates (same services, departures within 30 min) are dropped. If nothing is within tolerance, the least bad options are returned with `RISK_ABOVE_TOLERANCE`.
6. **Replan**: apply the delay; if all connections hold, return the same trip (`DELAY_ABSORBED`); else rejoin each later confirmed leg or route to the destination, preferring kept legs.
7. All thresholds live in `EngineOptions` with rationale. Output is deterministic (content-hashed ids).

New codes beyond CONTRACT: ARRIVAL_DEADLINE_TIGHT, SYNTHETIC_TIMETABLE, ASSUMED_LINK, ESTIMATED_FARE, RISK_ABOVE_TOLERANCE, DISRUPTION_DELAYED/CANCELLED, DELAY_ABSORBED, REPLAN_KEEPS_LEGS/NEW_LEGS/FULL_ROUTE. Notices: PLACE_UNKNOWN, ORIGIN_EQUALS_DESTINATION, NO_ROUTE_EXISTS, NO_SAFE_CONNECTION, CONNECTION_TOO_TIGHT, TAXI_UNAVAILABLE_AT_NIGHT, MODE_FILTER_EXCLUDES_ALL, BUDGET_EXCEEDED, MAX_TRANSFERS_EXCEEDED, EARLIEST_POSSIBLE_ARRIVAL, NO_SAFE_REPLAN, BOOKING_NOT_FOUND, DEADLINE_IN_PAST, SUGGEST_*.
